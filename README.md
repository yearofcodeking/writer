# writer — тексты для Telegram в Claude Code

> Напиши Claude «напиши закреп для моего канала» — он сначала выяснит, сколько сил ты вложил, а потом соберёт пост, после которого люди дочитывают до конца и пишут тебе в личку.

Это не генератор «продающих текстов». Скилл пишет твоим голосом, не выдумывает цифры и в каждом тексте показывает, что ты для читателя старался.

## Что умеет

- **Описание канала** в лимит Telegram (255 символов): кто ты, подарок со ссылкой, как написать.
- **Приветственно-продающий закреп**: заголовок с цифрой, что отдаёшь бесплатно, чем занимаешься за деньги, бесплатный первый шаг и кнопка в личку.
- **Обычные посты, подписи под видео, тексты кнопок.**
- **Заголовки**: пять приёмов, которые вызывают эмоцию, и проверка «я бы сам кликнул?».
- **Ценность**: находит в чате или спрашивает, сколько времени ушло, что переделывал, что стоило бы у других, и ставит это в текст.
- **Одна фраза везде**: призыв в тексте, надпись на кнопке и готовое сообщение в личку совпадают.
- Даёт 2–3 варианта и список проверки. Ничего не публикует сам.

## Установка

Две команды в терминале, потом перезапусти Claude Code:

```bash
claude plugin marketplace add yearofcodeking/writer
```

```bash
claude plugin install writer@writer
```

Обновление: `claude plugin marketplace update writer`. Удаление: `claude plugin uninstall writer@writer`.

## Что нужно заранее

Ничего, кроме Claude Code. Ключи и программы не нужны.

## Как пользоваться

Пиши обычными словами:

- «напиши описание для моего канала»
- «сделай закреп: отдаю бесплатно чек-лист, продаю консультации»
- «перепиши этот пост, чтобы дочитывали»
- «придумай текст для кнопки в личку»

Или явно: `/writer закреп`.

## Как устроено

```
.claude-plugin/marketplace.json
plugins/writer/
  .claude-plugin/plugin.json
  skills/writer/SKILL.md     — правила: ценность, заголовки, структура, лимиты Telegram, голос
  skills/writer/NOTICE.md    — откуда названия приёмов
```
